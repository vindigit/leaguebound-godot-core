# Independent final statistical review checklist

Do not inspect partial validation outcomes. Each validation phase must have all twenty process records, raw reports, canonical reports and logs before its audit proceeds. No extra games are authorized by this checklist.

1. Run `audit_phase_archive.py validation_a` and `validation_b`. This independently checks process/raw/report hashes, exact declared seeds/counts, runtime logs, complete canonical failure listings and unchanged metric definitions/denominators/targets across source/environment arms. Runtime errors and warnings are never treated as acceptable metric failures. Add `--output <new-path.json>` to retain results without overwriting evidence.
2. Verify all source freeze entries, the catalog comment amendment, and the exact candidate-only consumer-width exception. Preserve historical records. Verify every current tracked runtime file and contract against the applicable frozen hash; verify published Git blobs preserve evidence bytes. Do not infer broad source integrity from the three per-cell hashes alone.
3. Recompute all 300 canonical scalar estimates per phase from raw numerators/denominators. Preserve every canonical metric and failure, including metrics outside the paired diagnostic subset. Compare all target objects and verdicts with original canonical reports. No alternate target or tolerance is allowed.
4. Independently verify full-vector home/away and before/after roster marginal multisets, each quartet's AB/BA/BA/AB ordering, opener parity, same-input environment arms, exact seed pairing and disjoint diagnostic/A/B ranges. Retain local joint-support limitations.
5. Recompute 340 cell ratio intervals, 170 paired ratio intervals, thirty venue contrast intervals and ten paired SD bootstrap comparisons per phase. Audit event/complement-bearing and signed discordant-quartet counts, sparse flags and unavailable degenerate intervals. Preserve bootstrap seed and matched quartet sampling. No equivalence from nonsignificance.
6. Review both completed untouched ranges together without selecting results. Any directional language requires the preregistered non-sparse/nondegenerate conditions in both ranges and remains exploratory. Report remaining failures and any new failures. Separate population home-win diagnostics from the controlled three-arm estimand. No overtime-cause or complete-population certification claim follows.
7. Verify deterministic prefix replay separately after measurements and expensive gates finish; keep replay cells out of the experiment count. Verify the fresh complete eight-step gate, exact published head/CI, clean tree and draft/unmerged PR independently. Final acceptance cannot be assembled from partial gate reruns.
